# PI-MSCL 原生形状版：紧凑网格单元修订

本目录根据作者对“色块间距”的进一步澄清制作，未覆盖此前版本。此次不仅缩小白色描边，还实际放大 Input 色块，使 Input、Conv1D 和 Fuse 后融合张量的彩色网格都呈现更紧凑的单元排布。

## 推荐文件

- `PI-MSCL_architecture_native_shapes_fully_ungrouped_compact_cells_20260818.pptx`
  - 完全取消分组，555 个顶层原生对象。
  - 每个方格、叠板、箭头、曲线点和文本框均可直接单击编辑。

- `PI-MSCL_architecture_native_shapes_compact_cells_20260818.pptx`
  - 视觉相同的语义分组版，适合按模块整体移动。

## 本轮调整

- Input：原来采用 19 px 节距和 17 px 色块，实际几何空隙约 2 px；本版将色块对称放大为 18.2 px，使实际空隙缩小至约 0.8 px，同时保持不接触外框。
- Conv1D：9 个前表面网格的白色描边进一步缩小至原始宽度的 42%。
- Fuse 后融合张量：前表面彩色单元采用相同的 42% 白色描边宽度。
- 保留上一版已经确认的柔化叠板边框；面板、箭头、文字、公式、曲线与整体布局保持不变。
