# Triplet模式问题修复

## 问题1: RMSE计算错误 ✅ 已修复

### 症状
用户报告训练输出显示:
```
Val MAE:    1.0483%
Val RMSE:   0.0298%
```

RMSE (0.0298%) 远小于 MAE (1.0483%)，这在数学上是不可能的，因为 RMSE >= MAE（由Jensen不等式保证）。

### 根本原因

**文件**: [train_cross_battery.py:845](train_cross_battery.py#L845)

**错误代码**:
```python
val_rmse += ((predictions - targets) ** 2).sum().item()
```

**问题**: 这段代码只计算了 **Mean Squared Error (MSE)**，缺少了平方根操作！

对比其他模式的正确实现:
- **Pairwise模式** (line 878): `val_rmse += torch.sqrt(torch.mean((pred_t - y_t) ** 2)).item() * x_t.size(0)`
- **Standard模式** (line 904): `val_rmse += torch.sqrt(torch.mean((predictions - targets) ** 2)).item() * features.size(0)`

### 修复

**修改后的代码**:
```python
val_rmse += torch.sqrt(torch.mean((predictions - targets) ** 2)).item() * x_1.size(0)
```

**变化说明**:
1. 添加了 `torch.sqrt()` 计算平方根
2. 使用 `torch.mean()` 而不是 `.sum()` 以保持与其他模式的一致性
3. 乘以 `x_1.size(0)` 以正确累积batch的RMSE（后续会除以总样本数）

### 预期效果

修复后，RMSE应该正确显示为 >= MAE，例如:
```
Val MAE:    1.0483%
Val RMSE:   1.3521%  # 应该大于或等于MAE
```

## 问题2: 曲率损失变得非常小 ✅ 正常现象

### 用户疑问

用户观察到训练几个epoch后:
```
曲率损失 (2阶):  0.000002
```

担心约束是否失效。

### 分析

**这是完全正常且符合预期的现象！**

#### 曲率损失的含义

```python
# TripletPhysicsLoss中的曲率计算
curvature = pred_3 - 2*pred_2 + pred_1
curvature_loss = (curvature ** 2) * mask
```

**曲率的物理意义**:
- `curvature = 0`: 三个点共线，完美平滑
- `|curvature|` 大: 预测曲线有锯齿/振荡
- `curvature²` 接近0: 预测曲线平滑

#### 为什么损失变小是好事

当 `curvature_loss = 0.000002` 时，意味着:

1. **模型学会了平滑预测**:
   - 预测的SOH变化趋势一致（不会上下波动）
   - 三个连续时间点的预测接近共线

2. **物理约束生效了**:
   - 初期训练时，曲率损失应该较大（模型预测混乱）
   - 随着训练进行，约束引导模型学习平滑模式
   - 最终损失降低说明模型满足了约束

3. **类比单调性约束**:
   - 根据 [MONOTONIC_LOSS_ANALYSIS.md](MONOTONIC_LOSS_ANALYSIS.md) 的分析
   - 单调性损失为0意味着模型学会了容量衰减规律
   - 同理，曲率损失接近0意味着模型学会了平滑衰减

#### 数值示例

假设三个连续预测为:
```
pred_1 = 0.850
pred_2 = 0.845  # 下降0.005
pred_3 = 0.840  # 下降0.005
```

计算曲率:
```
curvature = 0.840 - 2*0.845 + 0.850
         = 0.840 - 1.690 + 0.850
         = 0.000  # 完美共线！
curvature_loss = 0.000² = 0
```

如果有锯齿（违反平滑性）:
```
pred_1 = 0.850
pred_2 = 0.855  # 上升！（违反单调性）
pred_3 = 0.845  # 下降

curvature = 0.845 - 2*0.855 + 0.850
         = 0.845 - 1.710 + 0.850
         = -0.015  # 有曲率！
curvature_loss = (-0.015)² = 0.000225  # 比0.000002大100倍！
```

### 如何验证约束确实生效

#### 方法1: 检查早期epoch

在训练刚开始时（epoch 1-5），曲率损失应该较大，例如:
```
Epoch [1/200]
  曲率损失 (2阶):  0.001234  # 初期较大

Epoch [10/200]
  曲率损失 (2阶):  0.000002  # 学习后变小
```

#### 方法2: 可视化预测曲线

对比有/无曲率约束的预测曲线:
- **无约束**: 可能出现 ↓↑↓↑ 锯齿模式
- **有约束**: 平滑单调下降 ↓↓↓↓

#### 方法3: 对比验证

训练两个模型:
1. `curvature_weight = 0.1` (当前设置)
2. `curvature_weight = 0.0` (禁用曲率约束)

对比预测曲线的平滑程度。

### 结论

✅ **曲率损失 = 0.000002 是正常且期望的**
- 表明模型学会了平滑预测
- 物理约束成功引导了学习
- 预测曲线应该不再有锯齿

❌ **如果曲率损失一直很大** (如0.01)
- 可能需要增加 `curvature_weight`
- 或检查模型是否收敛
