## 四、M6 专项验证结论（已关闭）

**Seeds 多组，Ratios = [0.3, 0.5]，batch_size=1024**

### 根因（最终版）

低监督率（r≤0.5）下标签不足 → 对无标注样本预测质量差（pseudo_mae 各轮次震荡 0.7%~2.2%）  
→ 伪标签引入方向性偏差 → early stopping 在 warmup 后立即触发（best_epoch=10）→ 退化

### 修复机制有效性

| 修复机制 | 效果 |
|---------|------|
| 单调过滤（use_mono_filter=True） | **最关键**，过滤违反物理约束的伪标签 |
| EMA 平滑（α=0.7） | 辅助，约 +0.5% |
| λ 自适应（r=0.3 用 λ=0.02） | 单独无效，配合使用有帮助 |
| min_epoch=10 门控 | 确保最优 checkpoint 落在伪标签生效后 |

### 关键数据点

| 场景 | MAE Δ% vs E0 | 说明 |
|------|:---:|---|
| r=1.0（消融主线 E5）| **+8.26%** ✅ | 无未标注样本，等同于 M2 集成效果 |
| r=0.7（消融主线 E5）| **+3.50%** ✅ | 部分监督下有效 |
| r=0.5（消融主线 E5）| −0.53% | 基本持平 |
| r=0.3（消融主线 E5）| −5.39% ❌ | 退化 |
| r=0.3，seed=42 单跑（三重修复）| +4.55% | 单 seed 有效但不稳定 |
| r=0.3，3 seeds 均值（三重修复）| −14.83% ❌ | 极不稳定，正式放弃 |

**结论：M6 在 r≥0.7 有效，r≤0.5 不可靠，不纳入 Full Stack。**

## 六、Full Stack（E7）结果分析

**配置：CNN-LSTM + M2 MC Dropout + M4 速率连续性**

| ratio | MAE% | Δ% vs E0 | mono_viol | 说明 |
|-------|:---:|:---:|:---:|---|
| r=1.0 | 1.1632% | +0.66% | 11.77% | 持平，未体现组合增益 |
| r=0.7 | 1.1778% | −2.66% | 11.68% | 略差于基线 |
| r=0.5 | **1.0884%** | **+4.74%** ✅ | 12.74% | 最佳表现 |
| r=0.3 | 1.2343% | **−15.40%** ❌ | **9.17%** | MAE 大幅退化，但违反率最低 |

> **r=0.3 问题**：MAE 退化 15.4%，但 mono_viol 9.17% 是 Full Stack 各 ratio 中最低，说明物理约束在低监督下仍生效，但代价是精度损失较大。需在论文中作 limitation 说明。
