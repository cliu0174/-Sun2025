## 五、M6 专项验证结论（已关闭）

**Seeds 多组，Ratios = [0.3, 0.5]，batch_size=1024**

### 根因（最终版）

低监督率（r≤0.5）下标签不足 → 对无标注样本预测质量差（pseudo_mae 各轮次震荡 0.7%~2.2%）  
→ 伪标签引入方向性偏差 → early stopping 在 warmup 后立即触发（best_epoch=10）→ 退化

### 修复机制有效性

| 修复机制 | 效果 |
|---------|------|
| 单调过滤（use_mono_filter=True） | **最关键**，过滤违反物理约束的伪标签 |
| EMA 平滑（α=0.7） | 辅助，约 +0.5% |
| λ 自适应（r=0.3 用 λ=0.02） | 单独无效，配合使用有帮助 |
| min_epoch=10 门控 | 确保最优 checkpoint 落在伪标签生效后 |

### 关键数据点

| 场景 | MAE Δ% vs E0 | 说明 |
|------|:---:|---|
| r=1.0（消融主线 E5）| **+8.26%** ✅ | 无未标注样本，等同于 M2 集成效果 |
| r=0.7（消融主线 E5）| **+3.50%** ✅ | 部分监督下有效 |
| r=0.5（消融主线 E5）| −0.53% | 基本持平 |
| r=0.3（消融主线 E5）| −5.39% ❌ | 退化 |
| r=0.3，seed=42 单跑（三重修复）| +4.55% | 单 seed 有效但不稳定 |
| r=0.3，3 seeds 均值（三重修复）| −14.83% ❌ | 极不稳定，正式放弃 |

**结论：M6 在 r≥0.7 有效，r≤0.5 不可靠，不纳入 Full Stack。**

### 6.2 M7 指标分析

- **PICP（理想值 0.95）**：仅 0.54~0.62，95% 置信区间只覆盖 54~62% 真值，区间严重偏窄
- **MPIW**：0.012~0.019，区间宽度很小，根因是 dropout_rate=0.1 产生的方差不足
- **Spearman**：r≥0.7 时有微弱正相关（0.10~0.12），r≤0.5 时降至 ≈0，不确定性与实际误差无关联
- **精度代价**：加入 M2 后，3/4 ratio 下 MAE 退化（−4.7%~−9.6%）

### 6.3 结论

**M7 不作为独立章节，降级为消融表中的辅助指标列。** 原因：
1. 校准质量差（PICP << 0.95），需要后处理校准但超出本文范围
2. Spearman ≈ 0（r≤0.5），说明不确定性估计在低监督下无信息量
3. 加入 M2 带来的精度损失抵消了不确定性估计的价值

### 7.5.3 Scene C：传感器漂移（drift = 0.05 / 0.10 / 0.20）

**分析**：
- 两模型漂移灵敏度相近；r=0.5 large drift（0.20）时 E0 ΔMAE 略低（0.2915% vs 0.3345%）
- 但**绝对 MAE** Exp09c 仍更低（1.5244% vs 1.5621%），实际性能更好
- r=0.3 时灵敏度差距压缩，两模型近乎持平

### 7.5.4 综合结论

| 扰动类型 | Exp09c 绝对 MAE | Exp09c 灵敏度（ΔMAE） | 总体判断 |
|---------|:---:|:---:|:---:|
| Scene A 特征缺失 | ✅ 全面更低 | ✅ n=3 更鲁棒 | Exp09c 胜 |
| Scene B 高斯噪声 | ✅ 全面更低 | ≈ 两者相当（量级<0.02%） | 持平 |
| Scene C 传感器漂移 | ✅ 全面更低 | ⚠️ 略高（<0.05% 差距） | 绝对值胜，灵敏度持平 |

**M8 核心结论**：PI-MS-CNN-LSTM（Exp09c）在 Clean 精度优势下，扰动场景中**保持甚至扩大优势**。多尺度架构在特征缺失场景下展示了更强的冗余性；对噪声/漂移的灵敏度与基线相当，不存在因架构复杂度引入的额外脆弱性。

## 八、最终方案与论文写作要点

### 8.1 各 ratio 最优方案

| 场景 | 最优方案 | MAE% | R² | 来源 |
|------|---------|:---:|:---:|------|
| r=1.0 | A1: MS-CNN-LSTM（无物理） | **1.0810%** | 0.9166 | 架构消融 |
| r=0.7 | Exp09c: PI-MS-CNN-LSTM（软单调） | **1.0745%** | 0.9297 | Exp-09 |
| r=0.5 | A1: MS-CNN-LSTM（无物理） | **1.0040%** | 0.9418 | 架构消融 |
| r=0.3 | Exp09c: PI-MS-CNN-LSTM（软单调） | **1.0336%** | 0.9398 | Exp-09 |

### 8.2 核心结论

1. **多尺度 CNN 是主要贡献**：2×3 对比矩阵中，架构维度（CNN→MS-CNN）的改善一致大于模块/约束维度的改善
2. **物理约束的作用是场景性的**：r=0.3 时软单调约束提供正则化增益（+3.1%），r≥0.5 时反而拖累精度
3. **M2+M4 在多尺度架构下冗余甚至有害**：MC Dropout 在低监督下引入过多推理噪声，速率连续性约束与多尺度特征提取冲突
4. **多尺度架构可能已隐式学习物理规律**：A1 standalone 的违规率虽高于 E0，但 Exp09c 在保持低违规率的同时获得最佳 MAE

### 8.3 论文写作要点

- **主线故事**：多尺度 CNN 通过多粒度特征提取隐式捕获退化规律，在部分监督场景下收益远超显式物理约束
- **消融表结构**：2×3 矩阵（架构 × 约束级别），突出架构维度贡献
- **Exp09c r=0.3 = 1.0336%** 作为全场最佳数据点重点展示
- A2（LayerNorm）失败原因值得在消融分析中解释（SOH 趋势序列的特殊性）
- M7 置信区间降级为消融表辅助指标（PICP=0.54~0.62，校准不足），不独立成章
- M2 不作为精度提升模块，仅在消融表中报告
- Full Stack E7 的 r=0.3 退化（−15.4%）与 Exp09c 的 r=0.3 最优形成对比，说明"更多模块 ≠ 更好"
- Exp-11 鲁棒性（M8）：Exp09c 绝对 MAE 全场更低；Scene A 特征缺失更鲁棒，Scene B/C 灵敏度持平；无架构复杂度引入的额外脆弱性
