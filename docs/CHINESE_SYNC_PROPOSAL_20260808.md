## 3. 建议的中文章节结构

1. 4.1 问题背景与研究缺口  
   以容量标定成本为工程动机，以 HUST 上的受控循环级标签预算为实验问题，不声称复现现场缺失。
2. 4.2 PI-MSCL 方法  
   依次说明输入与掩码、多尺度 CNN、LSTM、回归头、masked data loss 和软单调结构损失。
3. 4.3 实验设置  
   HUST 与 SOH 定义、16 维特征、电池级划分、标签保留协议、八个同协议模型、三种配对重复和评价指标。
4. 4.4 实验结果  
   标签预算主结果→八模型端点比较→统一轨迹指标→2×2 因子消融。
5. 4.5 讨论  
   条件性结构监督、负结果、随机掩码外推边界和单数据集限制。legacy anomaly-risk 暂不进入。
6. 4.6 小结  
   总结全监督 MAE 优势、30% 标签下的点精度劣势和同架构轨迹改善，不使用全面最优措辞。

## 4. 推荐的中文主线表述

> 本文并非证明 PI-MSCL 在任意标签预算下均具有最高预测精度，而是在严格跨电池、无预处理泄漏的 HUST 受控实验中，检验完整运行轨迹能否在循环级 SOH 标签减少时提供结构监督。结果表明，软单调约束能够在部分预算条件下改善点估计，并在 30% 标签端点稳定抑制同架构模型的非物理上升与轨迹粗糙度；但其点误差收益依赖监督锚点和训练种子，且普通 LSTM、GRU 或 attention CNN--LSTM 在若干误差或轨迹指标上更优。因此，本文贡献是标签预算协议、无泄漏跨电池验证和精度—物理规则性权衡，而不是模型的无条件全面领先。
