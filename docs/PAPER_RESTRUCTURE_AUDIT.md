### 3.1.1 中文源稿中必须隔离、重建证据的内容

中文稿是论述意图和技术说明的主要来源，但只读逐段审计发现以下事实不能直接转写：

1. **自建数据集**：中文稿多次声称使用面向实际运行场景采集的自建退化数据集，并给出 4 块自建电池等描述；当前本地未找到与这些陈述对应的完整原始数据、采集协议和可复现实验目录。除非作者补充并确认数据来源，否则正文主验证统一回到 HUST 受控稀疏标签协议，自建数据相关句子标为待证据，不得写成已完成实验。
2. **连续监督区间**：中文稿写为训练电池仅暴露生命周期的部分连续区间；当前代码实际是在每块训练电池内随机保留 `r` 比例的循环级标签。正文必须改为受控的电池内随机循环级标签掩码，不能声称已检验早期前缀外推或连续时间缺标。
3. **异常风险优势**：中文稿给出 PI-MSCL 在异常 AUC、检测率和延迟上明显优于 CNN-LSTM 的结论；现有 `docs/exp12_results_20260521.md` 反而记录不同模型 AUC 差异通常小于 0.01，物理约束和多尺度架构对检测能力几乎没有贡献。异常章节如保留，必须采用后续可追溯结果并如实报告弱或负结果，不能沿用中文稿中的高性能数字。
4. **结果数值版本**：中文稿中的部分 MAE/RMSE、消融改善幅度和模型排序，与 `docs/experiment_results_summary.md` 的 2026-05-06 最终方案记录不一致。中文稿数值只能作为旧版本线索，最终表格由可追溯结果重新汇总。

处理原则是“保留中文稿的问题动机、方法解释和讨论结构，重建数据协议、数值证据和结论强度”，而不是将中文稿视为未经核验的数值真值。

## 4. 当前实验与证据状态

### 4.1 已有主结果

本地汇总记录支持以下已完成实验线：

- 单模块消融；
- 架构消融 A0–A3；
- Exp-09 多尺度架构与物理约束组合；
- Exp-10 不确定性量化；
- Exp-11 特征缺失、噪声和漂移鲁棒性；
- Exp-12 人工异常注入探索。

当前最终模型记录为 PI-MS-CNN-LSTM / Exp09c：并行卷积核 3/7/15 + LSTM + 软单调约束。已有汇总显示多尺度结构是稳定的主要收益来源；软单调约束在 `r=0.3` 下提供正向收益，但在部分较高标签比例下存在精度代价。因此，正文应把物理约束写成“极低标签预算下的结构性正则化与轨迹约束”，不能声称其在所有标签比例下都改善精度。

### 4.2 原始结果可追溯性

实验文档引用的服务器目录，如 `experiments/ablation_single_module/metrics.json`、`experiments/exp07_full_stack/` 和 `experiments/exp09_ms_full_stack/`，当前本地并不完整存在。现有核心数值主要保存在 Markdown 汇总中，部分缺少逐种子原始记录和标准差。

处理规则：

- 能从逐种子 JSON/结果文件复算的数字直接复算；
- 仅存在于汇总文档中的均值可暂用于内容映射，但生成最终误差棒、显著性或置信区间前必须找回原始结果或重跑；
- 不从旧 PNG 反向读取数值。

### 4.3 随机重复口径问题

当前训练入口将 `seed` 同时传给随机初始化、电池级 Train/Val/Test 划分；当 `supervision_seed=None` 时，还将同一个 seed 用于标签掩码。现有 Exp-09 使用 `[929, 2262, 7]`，因此其三次结果同时改变：

1. 电池划分；
2. 标签掩码；
3. 模型初始化和训练随机性。

这些结果可以解释为“跨多个独立电池划分的重复验证”，且同一 seed 下不同 `r` 仍可配对比较；但不能写成“固定测试电池后只改变标签掩码”。若正文要采用后者，需要新增独立的 `split_seed`、`mask_seed` 和 `training_seed`。

### 4.4 指标单位一致性风险

旧结果文档中单调违反率同时出现约 `5%–20%` 和 `0.06%–0.25%` 两套量级，可能涉及比例/百分数转换、不同推理模式或统计定义差异。该指标在进入正文前必须从评价代码和原始预测重新计算，不能混用。

### 4.5 旧实验窗口管线存在比较混杂

`train_cross_battery.py::create_dataloaders` 的旧逻辑由 `use_physics` 决定窗口构造方式：

- 启用物理约束时，逐块电池独立窗口化并保留电池/循环元数据；
- 不启用物理约束时，先合并电池再滑动窗口，代码和日志均明确标为“跨电池窗口化”。

因此，位于电池边界附近的少量无物理模型输入窗口可能同时包含两块电池的循环。旧版 A1（多尺度、无物理）与 Exp09c（多尺度、软单调）的差异被“物理约束开关”和“窗口管线”共同影响，不满足严格二维消融的唯一变量原则。处理要求：

1. 新增与物理约束开关独立的 `preserve_battery_boundaries` 数据参数；论文实验统一设为 `True`；
2. 无物理和有物理模型均逐电池窗口化，保留相同元数据与标签掩码；
3. 旧结果只作开发历史，正文主结果和二维消融在统一管线上重跑；
4. 保留旧模式兼容开关仅用于复现，不再作为论文结果来源。

### 4.6 轨迹指标实现不一致

现有 Exp-09 在后验评价时调用 `compute_physics_violations(..., tolerance=0.01)`，而主模型训练配置使用 `monotonic_tolerance=0.005`；评价函数在缺少真实循环索引时还以组内相对位置近似 `min_cycle`。论文实验需保存每个预测的真实 `battery_id` 和窗口目标 `cycle_idx`，并以同一预先声明的容忍阈值重算轨迹指标。

### 4.7 旧跨电池预处理存在测试电池统计量泄漏

`load_all_batteries` 旧流程在 battery-level split 之前调用单电池加载器，并对每块电池的完整生命周期分别拟合 `StandardScaler`；随后合并数据后又进行一次训练集标准化。第一次标准化已经使用验证/测试电池自身均值和方差，因此旧结果不能视为严格的 unseen-cell evaluation。现已修正为：跨电池入口读取原始特征，先划分电池，再只在训练电池上拟合一次 scaler。单电池旧接口保留兼容默认值。修复后 10 项测试和 1-epoch CPU smoke 均通过；所有正式主结果仍须重跑。
