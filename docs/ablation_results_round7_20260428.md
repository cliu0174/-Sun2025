### ⚠️ 新遗留问题：负偏差自我强化

诊断日志（r=0.3，seed=42）中伪标签偏差跨 4 次更新的变化：

```
第 1 次更新  偏差: −0.06%  ← 可接受
第 2 次更新  偏差: −0.62%  ← 突变 ×10（根因）
第 3 次更新  偏差: −0.66%  ← 持续强化
第 4 次更新  偏差: −0.28%  ← 部分回调
```

**机制**：初始轻微低估 → 伪标签偏低 → 模型学偏 → 下一轮伪标签更偏 → 循环放大。  
σ 坍缩防护控制了**权重量级**，但没有纠正**方向性偏差**，故 r=0.3 的 MAE 和 mono_viol_rate 仍退化。

## 模块定性结论（本轮更新）

### ✅ M2 MC Dropout — 保留，核心贡献

- r=1.0 时 +4.42%，全表单模块最佳 MAE（0.00788）
- r<1.0 时基本持平（±1%），无退化
- **论文定位**：精度提升 + 置信区间估计的双重贡献

### ✅ M4 速率连续性 — 保留，物理一致性故事线

- MAE 一律 −1.5%（代价），但 r=0.5 单调违反率 2.89%（E0 的 57%）
- **论文定位**：精度与物理一致性存在 trade-off，M4 在物理保真度上贡献独立于 MAE

### ⚠️ M1 注意力 — 低标签率下有害，不单独使用

- r=1.0 实质无效（+0.05%，0.004 的 MAE 差，低于噪声水平）
- r=0.5 MAE −6.89%、mono_viol 12.84%（E0 的 2.5×）
- **疑因**：注意力权重在标签稀疏时过拟合到少量有标签循环的局部模式，破坏全局单调先验

### ~~❌❌ M5 自适应权重~~ — **正式放弃**

- r=1.0 MAE −12.02%，单调违反率 11.51%（E0 的 2.1×）
- 根因确认：可学习 log_var 在训练中将 monotonic_weight 持续压低，梯度信号失衡
- **决定**：不再投入排查资源，Full Stack 方案中去除 M5

### ❌ M6 伪标签（+M2）— 继续改进，分三方向

## M6 下一步改进计划（三方向最小验证）

### 三个修复方向

| 方向 | 目标问题 | 代码入口 | 可观测代理指标 |
|------|---------|---------|--------------|
| **EMA 平滑**（α=0.7） | 第 2 次更新偏差突变 | `PseudoLabelManager.update()` | `_print_diag` 中 `偏差` 行 |
| **单调性过滤** | mono_viol_rate 18.39% | `update()` 第 4 步后 | `[单调过滤] N/M passed` 行 |
| **λ_pseudo 自适应** | r=0.3 劣质标签破坏力 | 训练脚本初始化 PLM 时 | 最终 test MAE |

λ 映射方案：`{1.0: 0.03, 0.5: 0.05, 0.3: 0.02}`

### 最小验证实验（4 组 × 1 seed，仅跑 r=0.3，~1.5h）

| 组号 | EMA | 单调过滤 | λ 自适应 | 验证目的 |
|------|:---:|:-------:|:-------:|---------|
| E5_base | ✗ | ✗ | ✗ | 对照（已有） |
| E5_ema | ✅ | ✗ | ✗ | 第2次偏差是否被压制到 ≤0.2% |
| E5_filter | ✗ | ✅ | ✗ | 是否拦截到违规伪标签（过滤率>0） |
| E5_all | ✅ | ✅ | ✅ | 组合上限：MAE 是否回到 ±1% vs E0 |

不单独测 λ_only（保守，无 EMA 打底时被噪声掩盖；E5_all vs E5_ema+filter 的差值即 λ 贡献）。

### 决策树

```
E5_all 有效（MAE ≥ E0 ±1%, mono_viol < 10%）
    ├─ E5_ema 有效 → EMA 是核心
    ├─ E5_filter 有效 → 过滤是核心
    └─ 两者协同 → 论文里描述为"三重修复组合"

E5_all 仍然无效
    → 看第 2 次更新偏差是否被压制
    → 若仍漂移 → M6 在 r=0.3 根本不可靠，降级为"仅 r≥0.5 有效"
    → 若偏差稳但 MAE 差 → 问题是伪标签数量（提高置信阈值 top10%→top5%）
```
