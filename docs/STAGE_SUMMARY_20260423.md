# 阶段性工作总结（2026-04-23）

## 一、核心发现：物理约束是部分监督的底层机制

### 1.1 物理约束不只是正则化

本阶段最重要的发现是：**物理约束在部分监督场景中承担的不是"锦上添花"的正则化角色，而是让标签掩码机制真正生效的底层条件。**

原因在于损失函数的设计：

- `PhysicsConstrainedLoss`：接收 `supervision_mask`，对 `is_labeled=False` 的样本跳过 MSE，仅施加物理约束（单调性、边界）
- `nn.MSELoss`（物理约束关闭时）：不感知 `supervision_mask`，所有样本等权参与 MSE

这意味着关闭物理约束后，`ratio=0.5` 与 `ratio=1.0` 的训练完全等价——supervision_mask 形同虚设。

**验证实验结果（verify_physics_switch.py，2 seeds）：**

| 配置 | ratio | MAE mean% | RMSE mean% |
|------|-------|-----------|------------|
| physics_ON | 1.0 | 1.0176 | 1.7975 |
| physics_ON | 0.5 | 0.9963 | 1.6783 |
| physics_OFF | 1.0 | 1.0500 | 1.7407 |
| physics_OFF | 0.5 | **1.0500** | **1.7407** |

physics_OFF 下 ratio=0.5 与 ratio=1.0 结果完全相同，直接确认了上述机制。

### 1.2 物理约束对无标签样本的作用

对于 `is_labeled=False` 的样本，物理约束是其在训练中获得的**唯一梯度信号**：

```
单调性约束：告诉模型"这个样本的 SOH 预测值必须比前一个循环小"
边界约束：  告诉模型"SOH 预测必须在 [0,1] 之间"
```

物理先验替代了缺失的 SOH 数值监督，本质上是一种**结构性弱监督**。这一机制在低 ratio 场景（0.3 以下）预计效果最显著，因为无标签样本比例更高，物理约束承担的监督职责更重。

### 1.3 物理约束的贡献随 ratio 降低而增大

physics_ON 在 ratio=0.5 时（MAE=0.9963%）反而优于 ratio=1.0（MAE=1.0176%），初步支持以下假设：

> 较低 ratio 下，物理约束对无标签样本的规范使模型泛化更好，不确定性降低。

**这一假设需要 ratio=0.3 的完整实验数据进一步验证。**

## 二、已发现并修复的实验 Bug

### Bug 1：E0/E3 物理约束未开启（严重）

`cnn_lstm_config.json` 中 `physics_constraints.enabled = false`，但消融脚本 E0（Baseline）和 E3（M4 平滑性）未通过 `config_override` 开启物理约束：

- E0 实际运行的是**无物理约束的纯 CNN-LSTM**，与其他实验的对比不公平
- E3 的 override 只设置了 `smoothness_weight`，`enabled` 仍为 false，平滑性约束根本未生效，E3 等价于 E0

**修复**：在 E0/E3 的 `override` 中显式加入 `enabled: True`，`run_baseline_v22.py` 同步修复。

### Bug 2：physics_OFF 时 supervision_mask 未生效（严重）

`use_physics=False` 时使用 `nn.MSELoss`，该损失函数不接收 `supervision_mask`，导致所有样本（含无标签）均参与 MSE 计算。

**修复**：在训练循环中增加 `elif is_labeled is not None and not is_labeled.all()` 分支，非物理约束模式下也执行 masked MSE。

## 三、M1 注意力机制：暂缓，降低论文优先级

### 为什么降优先级

1. **功能重叠**：注意力作用于 LSTM 输出的 40 步序列，而 LSTM 在 40 步尺度上已能有效保留全部历史信息，窗口内 Self-Attention 的边际价值有限。

2. **真实收益来源存疑**：M1 在 RMSE 上的 11% 改善（ratio=1.0），更可能来自"Global Average Pool 替代最后一个隐状态"这一池化方式的改变，而非 Self-Attention 本身。LSTM 默认用 `h_T` 预测存在近期偏差，全局平均消除了这个偏差，这是真实有效的改动，但论文中本应单独验证。

3. **真正有价值的注意力**应是**跨窗口注意力**（对多个历史窗口的表征做 attention），捕捉 LSTM 完全无法感知的跨窗口长程退化规律，这超出当前论文范围。

### 后续处理

- 保留 M1 实现代码，不删除
- 论文叙述调整为"全局聚合替代近期偏差"，弱化 Self-Attention 的贡献主张
- 消融表中保留 M1 结果，但不作为核心创新点展开

## 四、下一步重心：M5 自适应权重

### 当前 M5 的设计问题

M5 基于 Kendall et al. (2018) 不确定性加权框架，存在以下问题：

**初始权重过高：**
`init_log_vars = [0.0, 0.0, 0.0, 0.0]` → 初始有效权重全部为 1.0，而固定权重 baseline 中单调性为 0.1、边界为 0.05。M5 训练开始时物理约束强度比 baseline 高 10-20 倍，会迅速拉高 log_σ 来压制物理项。

**不感知 supervision ratio：**
Kendall 方法响应的是各损失项的梯度不确定性，而非监督密度。低 ratio 时 MSE 总量变小，M5 可能反而降低物理权重以"平衡"两者量级，与期望方向相反。

**无 L2 正则：**
`l2_reg = 0.0` 使 log_σ 无约束增长，理论上可将某项损失权重趋近于零，物理约束有被自动关闭的风险。

### 改进方向

1. **修正初始值**：将 log_σ 初始化为与固定权重等效的值：
   ```python
   # exp(-log_σ) = weight → log_σ = -log(weight)
   init_log_vars = [0.0, -log(0.1), -log(0.05), 0.0]
   #              = [0.0,   2.303,    2.996,     0.0]
   ```

2. **加入 L2 正则**：防止某项被完全关闭，建议 `l2_reg = 0.01`

3. **ratio-aware 初始化**（可选，更激进）：
   ```python
   # ratio 越低，物理约束初始权重越高
   physics_init = -log(base_weight / supervision_ratio)
   ```

## 五、下一步重心：M2+M6 伪标签的可能性

### 机制梳理

M2（MC Dropout）和 M6（伪标签）是生产者-消费者关系：
- M2 对无标签样本做 50 次随机推理 → 得到 (μ, σ)
- M6 按 σ 升序筛选置信度最高的 30% 无标签样本
- 以 μ 作为伪标签，以 1/σ² 作为权重，进行辅助训练

### 核心约束

- **ratio=1.0 时 M6 完全无效**：没有无标签样本，伪标签模块跳过，E5 在 ratio=1.0 的退化完全来自 M2 的额外计算开销
- **真正的价值区间是 ratio ≤ 0.5**，尤其是 ratio=0.3（70% 样本无标签）

### 潜在问题

M6 的质量上限取决于 M2 的不确定性校准精度。MC Dropout 在小模型上的不确定性估计存在系统性偏差，可能对某些区间过度自信，导致引入错误的伪标签。建议在完整实验中监控伪标签的均值误差（伪标签 μ 与真实 SOH 的偏差）。

## 六、标签稀疏场景的设计反思

### 当前设计：随机掩码

每块电池内部随机选取 ratio 比例的循环有标签，标签均匀散布全生命周期。

**缺陷**：模型在全生命周期都能看到特征数据，只是部分循环没有 SOH 数值。物理约束很容易弥补这个缺口，导致 ratio=0.5 与 ratio=1.0 退化极小。

### 更有挑战性的场景：连续区间掩码

按生命周期连续区间划分，如"只有前 ratio 段有标签"：

```
早期监督（ratio=0.5）：
  [有标签] ████████████░░░░░░░░░░   前半生命周期有 SOH 测量
  [无标签]             ░░░░░░░░░░░   后半段靠物理先验外推
```

这更符合实际场景（早期可做容量标定，进入服役期后难以持续测量），也能最大化体现物理约束和 M6 伪标签的价值——无标签区间是连续的退化外推问题，比随机散点的缺失难得多。

**建议后续在 `generate_supervision_mask` 中增加 `mode='early'` 选项，作为主实验场景，现有随机掩码作为对比场景。**
