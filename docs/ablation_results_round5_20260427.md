## 关键结论（与第四轮 3 seeds 大幅反转）

1. **M2/M6 不再是 bug**：3 seeds 下 M2 −27%、M6 −77% 的灾难性退化在 5 seeds 下消失，**反转为正向 +4.4% / +3.1%**（ratio=1.0）。memory `project_experiment_status.md` 第三/四轮的"MC 推理噪声→灾难退化"诊断作废。
2. **M1 注意力反成退化项**：r=0.5 下精度 −6.9% + 违规率从 0.051 飙到 0.128。注意力打乱单调先验，需要额外正则才能保留。
3. **M5 全监督下最差**（−12%）：违规率 0.115 ≫ 基线 0.054 + smoothness 几乎没启用（init_log_var=5.0 → 权重 0.007）。可学习权重在训练中可能把 monotonic 也降下去了。
4. **M4 是唯一物理一致性赢家**：r=0.5 违规率减半，但精度全线 −1.5%~−2%。论文里作"物理保真度"卖点。
5. **M2+M6 在 r=0.3 违规率 0.184**：低标签率下伪标签噪声放大，需更严的置信筛选阈值。
6. **r=0.3 比 r=0.5 难，但只难一点**：所有方法在 r=0.3 下退化 0~5%，部分监督机制本身稳定。
